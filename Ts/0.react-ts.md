# React Ts

## 基础

### `FC`

* `React`结合`Ts`来写代码，你可能已经在多数情况下使用过了，但没有系统地学习过，以下是几个入门示例：

```tsx
const Avatar: React.FunctionComponent<AvatarProps> = ({ src, alt }) => {
  return <img src={src} alt={alt} />;
}
```

* 以上的代码，`React.FunctionComponent`是`React`提供的类型，你可以用`React.FC`简化，`AvatarProps`是泛型类型，用来约束`Avatar`组件的属性。
* 进阶玩法：你可以定义自己的类型，也可以指定泛型，这看起来特别有用（高级）

###`Element`

```tsx
const Ele: JSX.Element = <div>
  hello world
</div>

const Ele2: React.ReactElement = <div>
  hello world
</div>
```

* 实际上，这样的代码并无高级之处，只是为了让`Ts`能够识别`React`的类型而已。而现在大部分的编辑器已经能推导类型了（故没太大必要）。

```tsx
let Ele = <div>
  hello world
</div>

Ele = 0   // 根据类型推导，这里会报错，ts会提示你已经将Ele类型限制为 Element
```

### `ReactNode`

* `React.ReactNode`是一个通用类型，可以表示任何`React`元素，包括`null`、`boolean`、`string`、`number`、`JSX.Element`、`Array<ReactNode>`等。
* 比起`Element`，通用性更强

```ts
let Ele: React.ReactNode = <div>
  hello world
</div>

const bool: unknown = false

if (bool) {
  Ele = null      // 合理通过
}
```
