# jotai

* 与其他的`store`相比，`jotai`提供更简洁的原子，更易于理解的API。
* [https://jotai.org/](https://jotai.org/)
* [中文文档](https://lecepin.github.io/jotai-docs-cn/)

## 初使用

* 定义一个 `atom`
* 在`react component`中，使用`[atom] = useAtom(yourAtom)`获取它
* 在`react component`中，使用`[, update] = useAtom(yourAtom)`更新它

```ts
// 定义 store
import { atom } from 'jotai'

export const UserInfoAtom = atom({
  userId: '',
  authToken: '',
  name: '',
})

// 使用 in CompA
import { useAtom } from 'jotai'
import { UserInfoAtom } from './store/index.ts';

export default function Index () {
  const [userInfoAtom] = useAtom(UserInfoAtom)
}

// 更新 in CompB
export default function Index () {
  const [, updateUserInfoAtom] = useAtom(UserInfoAtom)

  const update = async () => {
    updateUserInfoAtom({
      // ...
    })
  }
}

```

## 进阶.派生

* `atom`可以进行"叠加""派生"以输出更多的精细化`atom`

```ts
const UserInfoAtom = atom({
  userId: '',
  authToken: '',
  name: '',
})

const useInfoTokenAtom = atom((get) => {
  const userInfo = get(UserInfoAtom)
  return userInfo.authToken
})
```
