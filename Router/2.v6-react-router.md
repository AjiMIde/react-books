# React Router v6

* [react-router.com](https://reactrouter.com/docs/en/v6)

## 变化

* 与`v5`相比`react router v6`有以下变化
* `Switch`变成`Routes`
* `useNavigate`替换了`useHistory`
* `component`变为`element`

```js
// v5
history.push('/home');
history.replace('/home');
 
// v6
navigate('/home');
navigate('/home', {replace: true});
```

## 安装

* 老规矩，安装`dom`库
* `cnpm i -S react-router-dom`

## 目标

* 大部分情况下，服务器都只提供`hash`路由模式（而非`history`）
* 最终配置需要达到：**路由嵌套**，**按需引入**，**动态路由**，**路由守卫**，**路由传参**
* **路由懒加载**，**404页面**，**重定向**，**权限控制**等功能
 
## 基本实现

```jsx
// in router
export function Router () {
  return (<HashRouter>
    <NavLink />
    <Routes>
      <Route path='/' element={<Home />} />
      <Route path='/about' element={<About />} />
      <Route path="/post" element={<Post />}>
        <Route path=":slug" element={<PostPage />} />
      </Route>
    </Routes>
  </HashRouter>)
}

// in post
import { Outlet } from 'react-router-dom';

function Post () {
  return (
    <div className='post-page'>
      Post page

      <Outlet />
    </div>
  )
}

// in App
function App() {
  return (
    <> <Router /> </>
  )
}
```


## 数据路由 ❗

* 正如官方文档所说，数据获取与整理几乎是必须的，提供"数据化"的路由配置也是必须的

```tsx
// in router/index.tsx

const routerData: RouteObject[] = [
  {
    path: '/',
    element: <Home />,
  },
  {
    path: '/about',
    element: <About />,
  },
  {
    path: '/post',
    element: <Post />,
    children: [
      {
        path: ':slug',
        element: <PostPage />,
      }
    ]
  },
]

export default function Router () {
  return <>
    { useRoutes(routerData) }
  </>
}

// in App.tsx
function App() {
  return (<div id='app'>
    <HashRouter>
      <Router />
    </HashRouter>
  </div>)
}
```
