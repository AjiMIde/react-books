# React Router v6

* [react-router.com](https://reactrouter.com/docs/en/v6)

## 变化

* 与`v5`相比`react router v6`有以下变化
* `Switch`变成`Routes`
* `useNavigate`替换了`useHistory`
* `component`变为`element`

```js
// v5
history.push('/home');
history.replace('/home');
 
// v6
navigate('/home');
navigate('/home', {replace: true});
```

## 安装

* 老规矩，安装`dom`库
* `cnpm i -S react-router-dom`

## 目标

* 大部分情况下，服务器都只提供`hash`路由模式（而非`history`）
* 最终配置需要达到：**路由嵌套**，**按需引入**，**动态路由**，**路由守卫**，**路由传参**
* **路由懒加载**，**404页面**，**重定向**，**权限控制**等功能


## `createBrowserRouter`

* 尽管后面我们不会使用这种模式，但还是了解一下
* 可以看出以`createBrowserRouter`及`element`属性来输出`provider`

```js
import "react";
import {
  createBrowserRouter,
  RouterProvider,
  Link,
} from "react-router-dom";

const router = createBrowserRouter([
  {
    path: "/",
    element: (
      <div>
        home <Link to="about">About Us</Link>
      </div>
    ),
  },
  {
    path: "about",
    element: <div>
      About <Link to="/">to home</Link>
    </div>,
  },
]);

export const BrowserRouterApp = () => {
  return (
    <RouterProvider router={router} />
  )
}
```

## `createHashRouter`

* 官网说了，只有不方便配置服务器时，才使用`hash`模式，这基本上是我们日常使用的
* 基本上是上面那个例子改了个`api`

```js
const router = createHashRouter([
  {
    path: "/",
    element: (
      <div>
        <h1>Hello World</h1>
        <Link to="about">About Us</Link>
      </div>
    ),
  },
]);
```


 
## `<HashRouter><Routers><Route>`实现路由配置，一般情况下也少用此模式

```jsx
// in router
export function Router () {
  return (<HashRouter>
    <NavLink />
    <Routes>
      <Route path='/' element={<Home />} />
      <Route path='/about' element={<About />} />
      <Route path="/post" element={<Post />}>
        <Route path=":slug" element={<PostPage />} />
      </Route>
    </Routes>
  </HashRouter>)
}

// in post
import { Outlet } from 'react-router-dom';

function Post () {
  return (
    <div className='post-page'>
      Post page

      <Outlet />
    </div>
  )
}

// in App
function App() {
  return (
    <> <Router /> </>
  )
}
```
