## 参数 useParams 与 useSearchParams

```js
const params = useParams()        // 匹配 router 设置中 /path/path/:paramA/:paramB 的参数
const [urlSearchParam, setUrlSearchParam] = useSearchParams()  // 匹配 url 中的 search 参数
const urlSearch = Object.fromEntries(urlSearchParam)   // URLSearchParams 对象，这一步须转一下
```
