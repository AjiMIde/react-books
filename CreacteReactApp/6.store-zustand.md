# Zustand React 状态管理器

* [zustand](https://github.com/pmndrs/zustand)
* 使用`flux`原则的一个简单的状态管理器解决方案
* 使用了简单的`hooks API`
* 简单，反传统，不需要写`action，reducer，dispatch`
* 无需`provider`


## 初步使用
```js
import { create } from 'zustand'

const usePersonStore = create((set) => ({
  age: 0,
  increase: () => set((state) => ({ age: state.age + 1 })),
}))

const CompA = () => {
  const age = useCountStore(state => state.age)
}

const CompB = () => {
  const increase  = useCountStore(state => state.increase)
}
```

## 取值
```js
const usePersonStore = create((set) => ({
  age: 0,
  name: 'zhangsan',
  increase: () => set((state) => ({ age: state.age + 1 })),
  changeName: (name) => set((state) => ({ name })),
}))

const CompA = () => {
  // 常规取值 
  const age = useCountStore(state => state.age)
  
  // 实际上，以下面这种取值来说，当 name 都被更新时，此组件也会被重新渲染
  // 理由是 state 已被引用
  const { age } = useCountStore(state => state)
  // const name = useCountStore(state => state.name)
  
  // 解决方案是，只取需要的值
  const age = useCountStore(state => state.age)
  
  // 或者使用 shallow
  import { shallow } from 'zustand/shallow'
  const { age } = useCountStore(state => state, shallow)
}
```

## 对比函数

* 对比函数，只有当函数返回的值不同，才会触发重新渲染
```js
const age = usePersonStore((state) => state.age, (o, n) => {
  const bool = n > o && n > 5
  return bool // 当 bool 为 false 时，才更新 age (挺神奇的)
})

```
