# ref

* 正常这么用，肯定没问题：

```jsx
const A = () => {
  const ref = useRef(null);

  return (
    <div>
      <input type='text' ref={ref} />
    </div>
  )
}
```

* 如果封装了组件，那就不行了
 
```jsx
function B (props) {
  return <input {...props} />
}

const A = () => {
  const ref = useRef(null); // 此时 ref 没有指向

  return (<div>
      <B ref={ref} />
    </div>
  )
}
```

## React.forwardRef

* `React.forwardRef`就是为了解决这样的问题，专业术语叫：前向引用组件
* **注意** `ref`不能省略

```jsx
const B = React.forwardRef((props, ref) => {
  return <input ref={ref} {...props} />
})
```

* 在`tsx`中，你还需要用`React.ForwardRefExoticComponent`来约束组件类型

```tsx
const MyComponent: React.ForwardRefExoticComponent<MyComponentProps> = React.forwardRef((props, ref) => {
  // 组件实现...
  return <div {...props} ref={ref} />;
});
```
