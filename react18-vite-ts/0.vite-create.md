## 目录推荐

* 你可以在本目录中的 `template/`下拿到以下内容
* src/component: 通用组件
* src/pages: 通用页面
* src/layout: 通用布局
* src/util: 通用工具
* src/model: 通用模型
* src/service: 通用服务
* src/assets: 通用资源
* src/style: 通用样式
* src/config: 通用配置
* src/locale: 通用语言
* src/types: 通用类型
* src/hooks: 通用钩子

## 配置别名

* 理论上配置完别名，基础的配置基础也有了：
* PS: `webstorm`上如果配置失败，请在`settings`中检查`vite config`相关引用

```bash
npm add @types/node -D  # 为了使`vite.config.ts`中的`node`模块生效，须引入`@types/node`
```

```ts
// in vite.config.ts
import { defineConfig } from 'vite'
import path from 'path';                        // node 中的 path 模块
import { fileURLToPath, URL } from 'node:url';  // node 中的 url 模块

const __dirname = fileURLToPath(new URL('.', import.meta.url));
const resolve = (dir: string) => path.join(__dirname, dir);

export default defineConfig({
  resolve: {
    alias: {
      '@': resolve('src')
    }
  }
})
```

* `in tsconfig.json: 配置 paths`

```js
const config = {
  "compilerOptions": {
    /*alias*/
    "baseUrl": "./",
    "paths": {
      "@/*": ["src/*"]
    }
  }
}
```

## scss

```bash
# 使用`sass`请安装以下
pnpm add sass -D

# 2024年，你还可以安装以下，据说更快
pnpm add sass-embedded -D
```

* 如果你定义了`variable.scss`，那可以在`vite.config.ts`中配置如下，这样可以在所有`scss`文件中引用`variable`

```js
const cofig = {
  css: {
    preprocessorOptions: {
      scss: {
        additionalData: `@import './src/style/variable.scss';`, // 根据你的项目结构调整路径
      },
    },
  }
}
```

* `css.reset`，如果你引用了`fzs-amazing-builder`，则直接引用其`reset`即可，否则，则自行复制`fzs-amazing-builder`中的`reset`到`src/style/reset.scss`中

## antd

* 一般需要注意在 `App.tsx`中使用`ConfigProvidea.locale=zhCn`来处理中文 

```bash
* pnpm add antd -S
```

```tsx
import { ConfigProvider } from 'antd'
import 'dayjs/locale/zh-cn';
import zhCN from 'antd/locale/zh_CN';

// in App.tsx
return (
  <ConfigProvider locale={zhCN}>
  </ConfigProvider>
)
```
