## vite-plugin-react

* 将`react`相关的`plugin`合一配置，主要是`[vite-plugin-react-swc], [vite-plugin-react-refresh], [vite-plugin-react-pages]`
* [github document](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md)
* 有以下特点：**更快刷新**，**开箱的babel**，**开箱的jsx支持**等

```ts
// vite.config.js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
})
```

## 相关配置

* **`include`** 天然支持`js`, `ts`，`jsx`，`tsx`，一般无须配置，除非你想配置`mdx`(一种`markdown`的`jsx`语法)
* **`babel`** 支持`babel`相关配置，如下：

```ts
react(
  {
    babel: {
      presets: [...],     // 预先
      plugins: [...],     // 插件
      babelrc: true,    // 是否使用 .babelrc 文件
      configFile: true, // 是否使用 babel.config.js 文件
    }
  }
)
```
 
* 以下均为默认配置（或罕见配置）
* `jsxImportSource`
* `jsxRuntime`
* `Middleware mode`

## 错误1：optionalChainingAssign

* 在对`ref`对象进行`dom`操作时，使用链式赋值时，会报错

```tsx
titleRef.current?.innerHTML = 'hello world'
```

* `optionalChainingAssign`可选链式赋值
* `[plugin:vite:react-babel] index.tsx: Support for the experimental syntax 'optionalChainingAssign' isn't currently enable`
* 出现这个错误，理论上应该分析`vite+react`肯定是有默认`babel`配置，提示说要继续`babel`配置
* 寻问两个`AI`，均提示安装`@babel/plugin-proposal-optional-chaining`，安装后，配置此：

```ts
// vite.config.js
plugins: {
  react({
    babel: {
      plugins: ['@babel/plugin-proposal-optional-chaining']
      // ["@babel/plugin-proposal-optional-chaining", {"version": '2023-07', legacy: true, loose: true}],
    }
  })
}
```

* 以上均失效，四处寻找原因，发现库不应为`@babel/plugin-proposal-optional-chaining`，应为`@babel/plugin-proposal-optional-chaining-assign`
* 安装配置后，问题解决

```ts
["@babel/plugin-proposal-optional-chaining-assign", { version: '2023-07' }]
```

* 然而，`eslint`通过，`ts`并不能通过
* `TS2779: The left-hand side of an assignment expression may not be an optional property access.`
* 左边的表达式用于赋值，不能是可选属性访问，这大概率是`ts`为了避免类型错误的问题
* 避免这种情况，其实就不应该使用`?.`链式赋值，使用以下语法

```tsx
titleRef.current!.innerHTML = 'hello world'     // 不是很推荐

titleRef.current ? titleRef.current.innerHTML = 'hello world' : null;     // 比较推荐

```
